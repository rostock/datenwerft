# *Stadtbereichskatalog* → Startseite (Dashboard)

Über die Startseite der App *Stadtbereichskatalog,* das sogenannte Dashboard, gelangen Sie
in alle Bereiche und auch direkt zu allen wesentlichen Aktionen. Von links nach rechts
und von oben nach unten gliedert sich das Dashboard wie folgt:

- Bereich **Metadaten:**
  - Link auf die [Tabelle](metadata/table.md) mit allen vorhandenen **Themenbereichen**
  - Link auf die [Tabelle](metadata/table.md) mit allen vorhandenen **Kategorien**
  - Link auf die [Tabelle](metadata/table.md) mit allen vorhandenen **Quellenangaben**
  - Link auf die [Tabelle](metadata/table.md) mit allen vorhandenen **Indikatoren**
- Bereich **Referenzdaten:**
  - Link auf die [Tabelle](reference_data/table.md) mit allen vorhandenen **Kandidat:innen**
  - Link auf die [Tabelle](reference_data/table.md) mit allen vorhandenen **Parteien**
- Bereich **Faktendaten:**
  - Link auf die Seite mit der Möglichkeit zum [Export](data/export.md) von Faktendaten
  - Link auf die Seite mit der Möglichkeit zum [Import](data/import.md) von Faktendaten
  - Link auf die Seite mit der Möglichkeit zur [Bearbeitung](data/editing.md) von Faktendaten
  - Link auf die Seite mit der Möglichkeit zum [Löschung](data/deletion.md) von Faktendaten
